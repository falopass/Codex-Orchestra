# Codex Router adapter

Typed contract for the external [Codex Router](https://github.com/duolahypercho/codex-router) engine.

Orchestra does not vendor Router. The reviewed pin is `v0.4.0-beta.3` (`a1be46aa02426d87a9e24e114ce8c22619c63c7a`). Mutating operations require confirmation. Bind address is `127.0.0.1`.

See [engine/README.md](../../engine/README.md) and [docs/OPERATIONS.md](../../docs/OPERATIONS.md).
